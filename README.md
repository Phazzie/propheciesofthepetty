# Prophecies of the Petty

## Project Description
Prophecies of the Petty is a project aimed at providing insightful and humorous prophecies. The project leverages modern web technologies to deliver a seamless user experience.

## Features
- User-friendly interface
- Random prophecy generation
- Shareable prophecies

## Installation
1. Clone the repository
   ```sh
   git clone https://github.com/yourusername/propheciesofthepetty.git
   ```
2. Navigate to the project directory
   ```sh
   cd propheciesofthepetty
   ```
3. Install dependencies
   ```sh
   npm install
   ```

## Usage
To start the development server, run:
```sh
npm start
```
